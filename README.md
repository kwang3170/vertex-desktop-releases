# Vertex Studio desktop — releases

Installers for the Vertex Studio student desktop app. Binaries only; the source is private.

Download the latest from the [Releases page](../../releases/latest), or from https://app.vxai.com.au/download.

**macOS (Apple silicon):** open the `.dmg` and drag Vertex to Applications. The build is not notarized yet, so the first time, right-click Vertex → **Open** (or System Settings → Privacy & Security → **Open Anyway**).
